# Cynbit SmartConnect — Technical Report

## 1. Project overview
Cynbit SmartConnect is an independent prototype that proposes a guided project-planning and inquiry experience.

## 2. Problem statement
The assessment asks the applicant to inspect Cynbit's existing website and identify one meaningful improvement. After inspecting the live site, document the specific observed friction here. Do not present an unverified assumption as an existing defect.

## 3. Proposed improvement
Describe how the Smart Project Planner helps a visitor choose a service, select requirements, specify a timeline and budget, and submit a structured inquiry.

## 4. Technology stack
- React and Vite: interactive frontend
- CSS: responsive styling
- Node.js and Express: REST API
- MongoDB and Mongoose: inquiry storage
- Git and GitHub: source control

## 5. Implementation
Explain the planner, inquiry API, database schema, validation, and protected admin endpoints.

## 6. Testing
Record actual results for mobile layout, required-field validation, valid inquiry submission, database persistence, and protected admin access.

## 7. Results
Add screenshots and measured test results from your own run.

## 8. Limitations and future improvements
Possible future work: proper admin login with hashed passwords and sessions, email notifications, rate limiting, spam protection, accessibility audit, and automated tests.

## 9. Conclusion
Summarise what you implemented and how it addresses the improvement you personally observed.
